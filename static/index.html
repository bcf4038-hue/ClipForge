Montage: join several short clips into one Short

The list order is the ranking: the top row is #1. The video counts down and shows #1 last. Auto-pick ranks them for you. Give each clip an optional label.

Add them in any order, then use the arrows. Trim each one so only the best part stays.

From/To are optional for videos under 20 minutes. For longer ones, type the part you want (like 12:30 to 13:10) so it only downloads that part.

Tip: pause the player, then use "Start = now" or "End = now" on a clip to trim it exactly.
