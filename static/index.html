AI spending

Only the Find clips step costs money. Downloading, captions, Whisper and rendering are free. You are always asked before anything is charged.

Set this to the credit you bought. ClipForge counts what it spends and warns you before you go over. It can't see your real balance, so check console.anthropic.com (Billing) now and then. ClipForge's numbers are close estimates; the Console is the official bill.

Montage

Join your own clips or links into one Short. Plain montage, or a top list countdown.

The list order is the ranking: the top row is #1. The video counts down and shows #1 last. Auto-pick ranks them for you. Give each clip an optional label.

Add them in any order, then use the arrows. Trim each one so only the best part stays.

From/To are optional for videos under 20 minutes. For longer ones, type the part you want (like 12:30 to 13:10) so it only downloads that part.
